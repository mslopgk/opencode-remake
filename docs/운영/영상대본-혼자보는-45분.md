# 영상 대본 — 혼자 보고 따라 하는 설치·사용법 (45분)

대상: 초등학교 5학년 ~ 중학교 1학년
상황: **집에서 혼자.** 도와주는 사람이 없습니다.

> 이 대본은 **녹화용**입니다. 학생은 이 영상을 혼자 보면서 자기 노트북에
> 설치합니다. 조교도, 선생님도, 학부모도 옆에 없다고 가정합니다.

---

## 이 대본이 현장 강의와 다른 점 (촬영 전에 반드시 읽으세요)

### 1. "손 들어 보세요" 가 없습니다

혼자니까 손을 들 사람이 없습니다. 대신 **"화면이 이렇게 보이나요?"** 로
스스로 확인하게 합니다. 그리고 **틀린 화면도 보여줍니다.**
맞는 것만 보여주면, 자기 화면이 다른데도 다른지조차 모릅니다.

### 2. 기다리는 시간을 찍지 않습니다

다운로드 8분, 설치 7분을 실시간으로 찍으면 볼 게 없는 15분이 됩니다.
대신 **"영상을 멈추고 기다리세요"** 라고 말합니다.
학생은 자기 노트북 앞에서 기다리면 됩니다.

그렇게 아낀 15분을 **"틀렸을 때 어떻게 하는지"** 설명에 씁니다.
혼자 하는 학생에게는 그게 제일 필요합니다.

### 3. 막히면 포기합니다

옆에 아무도 없으면 한 번 막히면 그냥 덮습니다.
그래서 **거의 모든 절 끝에 이 말을 넣습니다.**

> "안 되면 그냥 두고 캠프 날 오세요. 5분이면 고쳐 드려요."

이 말이 없으면 아이가 밤에 혼자 붙들고 스트레스를 받습니다.

### 4. 일시정지를 계속 시킵니다

영상의 최대 장점입니다. **"여기서 멈추고 해 보세요"** 를 아끼지 마십시오.

## 촬영 방법

### 화면 녹화 + 목소리

강사 화면을 녹화하면서 말합니다. 얼굴은 없어도 됩니다.
**학생이 볼 화면과 똑같은 것을 보여주는 게 제일 중요합니다.**

### 절 단위로 따로 찍으세요

11개 절을 하나씩 따로 찍습니다. 하나 망쳐도 그것만 다시 찍으면 됩니다.
파일 이름을 번호로 저장하십시오.

```
01-시작안내.mp4
02-인터넷열기.mp4
03-주소입력.mp4
...
11-마무리.mp4
```

다 찍으면 이어붙이기·제목카드·음량정리는 따로 해 드립니다.

### 반드시 미리 준비할 것 — "틀린 화면"

이 대본은 틀린 화면을 보여주라고 여러 번 요구합니다.
**전부 일부러 만들 수 있습니다.** 방법을 아래에 적어 뒀습니다.

- [ ] 검색창에 `camp.kodekorea.kr` 을 치고 엔터 → 검색 결과 화면
      (결과가 **잔뜩 나옵니다.** "아무것도 안 나온다" 고 말하지 마십시오)
- [ ] 주소를 틀리게 친 화면 (`camp.kodekorea.kt` 등) → "찾을 수 없음"
- [ ] 파란 화면 (Windows가 PC를 보호했습니다)
- [ ] **점검에서 빨간불이 하나 있는 화면**

#### 점검 빨간불을 일부러 띄우는 방법

진짜 오류가 날 때까지 기다릴 필요 없습니다. **가짜 실패 모드**가 있습니다.

PowerShell 창을 하나 열고 아래를 그대로 붙여 넣으십시오.

```powershell
$env:CAMP_SELFCHECK_FAKE = 'partial'
& "$env:LOCALAPPDATA\창의디자인캠프-설치\점검.exe"
```

그러면 **여섯 개 중 두 번째만 빨간불**로 나옵니다. 실제로 가장 흔한
실패 모습이라 촬영에 그대로 쓰기 좋습니다.

| 값 | 결과 |
|---|---|
| `partial` | 두 번째 항목만 빨간불 ← **촬영에 이걸 쓰세요** |
| `fail` | 여섯 개 전부 빨간불 (너무 무섭게 보입니다) |
| `ok` | 여섯 개 전부 초록불 |

찍고 나면 그 PowerShell 창을 닫으십시오. 창을 닫으면 설정도 사라집니다.
바탕화면 아이콘으로 실행하면 원래대로 진짜 점검을 합니다.

#### 파란 화면을 일부러 띄우는 방법

인터넷에서 **새로 받은 파일을 처음 실행할 때만** 나옵니다.
이미 한 번 실행한 컴퓨터에서는 다시 안 나옵니다.

- 설치 파일을 **새로 받으면** 다시 나옵니다 (파일이 바뀌면 처음으로 취급)
- 또는 **다른 사용자 계정**에서 받아 실행하면 나옵니다
- 또는 파일을 지우고 `camp.kodekorea.kr` 에서 다시 받으면 나옵니다

# 1. 시작 안내 (2분)

### 【그대로 읽으세요】

> "안녕하세요! 창의디자인캠프에서 쓸 프로그램을 같이 깔아 볼 거예요.
> 혼자 해도 괜찮아요. 선생님이 하나씩 다 알려 줄 거예요.
>
> 먼저 **세 가지**만 약속해요.
>
> **첫째, 이 영상은 멈출 수 있어요.**
> 선생님이 '멈추세요' 하면 영상을 멈추고 천천히 하세요.
> 급하지 않아요. 다 하고 다시 재생하면 돼요.
>
> **둘째, 잘 안 보이면 뒤로 돌려 보세요.**
> 다시 보고 싶으면 몇 번이든 돌려 봐도 돼요.
>
> **셋째, 이게 제일 중요해요.**
> 하다가 안 되면요? **그냥 두고 캠프 날 오세요.**
> 캠프 첫날 아침에 선생님이 5분이면 고쳐 드려요.
> 혼자 오래 붙들고 있지 마세요. 진짜로 괜찮아요.
>
> 자, 그럼 시작해 볼까요? 준비물은 **윈도우 노트북** 하나예요."

### 화면에 띄울 것

```
멈추기       →  영상을 멈추고 천천히
뒤로 돌리기   →  몇 번이든 다시 봐도 돼요
안 되면      →  그냥 두고 캠프 날 오세요
```

# 2. 인터넷 열기 (3분)

### 【그대로 읽으세요】

> "먼저 **인터넷**을 열어야 해요.
>
> 바탕화면이나 화면 아래 막대를 보세요.
> 이런 그림이 있을 거예요."

### 화면에 보여줄 것 — 브라우저 아이콘 3종

**엣지·크롬·웨일 아이콘을 나란히 보여줍니다.** 노트북마다 다릅니다.

> "이런 그림들 중에 하나가 있을 거예요. 다 인터넷이에요.
> 파란 물결 모양, 빨강노랑초록 동그라미, 파란 동그라미 —
> 뭐든 하나 있으면 돼요.
>
> 바탕화면에 있으면 **두 번** 누르세요. 딸깍딸깍.
> 화면 **아래 막대**에 있으면 **한 번**만 누르면 열려요.
>
> 자, 지금 **영상을 멈추고** 인터넷을 열어 보세요."

### 【다시 재생한 뒤】

> "열렸어요? 이렇게 하얀 화면이나 검색 화면이 나오면 맞아요."

### 화면에 보여줄 것 — 열린 브라우저

### 【안 될 때 — 스스로 해결하게】

> "안 열렸으면 이렇게 해 보세요.
>
> 화면 **왼쪽 아래**에 있는 **윈도우 표시**를 한 번 누르세요.
> 네모 네 개가 모인 그림이요.
> 그러면 프로그램 목록이 나와요.
> 거기서 아까 본 그림 중 하나를 찾아 한 번 누르세요.
>
> 그래도 안 되면 그냥 두고 캠프 날 오세요."

# 3. 주소 입력 ★ 가장 어려움 (7분)

**이 절이 이 영상의 성패를 결정합니다.** 절대 빨리 넘기지 마십시오.

## 3-1. 주소창과 검색창 구분 (2분)

### 【그대로 읽으세요】

> "이제 제일 중요한 부분이에요. 잘 들어 주세요.
>
> 화면에 글씨 쓸 수 있는 칸이 **두 개** 보일 수 있어요.
> 이게 오늘 제일 헷갈리는 부분이에요."

### 화면에 보여줄 것 — 두 칸에 화살표와 이름 표시

```
┌──────────────────────────────────────┐
│ ← 주소창 (맨 위, 길쭉함) ★ 이걸 써요   │
├──────────────────────────────────────┤
│                                      │
│         ○ 검색창 (가운데, 동그람)      │
│           ← 이건 쓰면 안 돼요          │
└──────────────────────────────────────┘
```

> "**맨 위**에 있는 길쭉한 칸. 이게 **주소창**이에요. 오늘 쓸 거예요.
>
> **가운데**에 있는 동그란 칸. 이건 **검색창**이에요. 오늘 안 써요.
>
> 검색창에 쓰면 어떻게 되는지 보여 줄게요."

### 화면에 보여줄 것 — 검색창에 쳤을 때 (틀린 화면)

**실제로 검색창에 치고 엔터를 누릅니다.**

> ⚠ **촬영 주의**: 검색하면 **결과가 잔뜩 나옵니다.**
> 코드코리아 인스타그램, 다른 사이트, 구글 AI 설명까지 나옵니다.
> "아무것도 안 나온다" 고 말하면 화면과 어긋나 아이가 헷갈립니다.
> 아래 대본대로 **"우리가 받을 곳이 여기 없다"** 로 말하십시오.

> "보세요. 뭔가 잔뜩 나오죠?
> 그런데 잘 보세요. **우리가 받을 곳은 여기 없어요.**
>
> 코드코리아 인스타그램, 다른 사이트들… 다 우리가 찾는 게 아니에요.
> 우리 프로그램은 **우리 캠프만 쓰는 주소**라서 검색으로는 못 찾아요.
>
> 여기서 아무거나 누르면 엉뚱한 곳으로 가요.
> 그러니까 검색창이 아니라 꼭 **맨 위 주소창**에 써야 해요.
>
> 자, **영상을 멈추고** 자기 화면에서 맨 위 길쭉한 칸을 찾아보세요.
> 찾았으면 **한 번 콕** 누르세요."

## 3-2. 주소 치기 (4분)

### 【다시 재생한 뒤】

> "눌렀으면 안에 있던 글씨가 파랗게 됐을 거예요. 그 상태면 맞아요.
> 이제 그냥 치면 원래 있던 건 지워져요.
>
> 칠 주소는 이거예요. 화면에 크게 띄워 놨어요."

### 화면에 보여줄 것 — 주소를 아주 크게

```
camp.kodekorea.kr
```

> "**영어**로 써요. 한글로 나오면 **한/영** 키를 한 번 누르세요.
> 스페이스 바 왼쪽이나 오른쪽에 있어요.
>
> 천천히 같이 쳐 볼게요. 선생님이 치는 걸 보면서 따라 하세요.
>
> **c** … **a** … **m** … **p**
> 캠프예요. `camp`
>
> 그다음 **점**. 마침표요. 쉼표 아니에요. 점이에요.
>
> **k** … **o** … **d** … **e**
> 코드. `kode`
>
> **k** … **o** … **r** … **e** … **a**
> 코리아. `korea`
>
> 그다음 또 **점**.
>
> **k** … **r**
> 케이알. `kr`
>
> 다 됐어요? `camp` 점 `kodekorea` 점 `kr`"

### 화면에 보여줄 것 — 주소창에 정확히 입력된 상태 (확대)

> "자, 지금 **영상을 멈추고** 자기 화면과 이 화면을 비교해 보세요.
> 똑같아요? 점 두 개 다 있어요? 띄어쓰기는 없어야 해요.
>
> 확인했으면 다시 재생하세요."

## 3-3. 엔터와 틀렸을 때 (1분)

### 【다시 재생한 뒤】

> "이제 **엔터**를 누르세요.
> 키보드 오른쪽에 있는 꺾인 화살표 큰 키요.
> **한 번만** 누르세요."

### 화면에 보여줄 것 — 다운로드가 시작된 화면

> "이렇게 뭔가 받아지기 시작하면 성공이에요!"

### 【틀렸을 때 — 두 가지 경우를 다 보여준다】

> "그런데 이렇게 나올 수도 있어요."

### 화면에 보여줄 것 — "찾을 수 없습니다" 화면

> "이건 주소를 잘못 쓴 거예요. 고치는 법은요,
> 맨 위 주소창을 **한 번** 누르고, 다 지우고 다시 쳐 보세요.
> 지우는 건 **백스페이스** 키예요. 엔터 위에 있는 긴 키요.
>
> 제일 많이 틀리는 곳 세 군데를 알려 줄게요.
>
> 하나, **점을 쉼표로** 친 것. 점이에요.
> 둘, **kr 을 kt 나 co 로** 친 것. 케이알이에요.
> 셋, **한글로** 쓴 것. 한/영 키를 누르세요."

### 화면에 보여줄 것 — 검색 결과 화면 (또 다른 틀린 경우)

> "이렇게 검색 결과가 나왔으면, 검색창에 쓴 거예요.
> 여기엔 우리가 받을 곳이 없어요. **맨 위 주소창**에 다시 쓰세요.
>
> 세 번 해도 안 되면 그냥 두고 캠프 날 오세요. 괜찮아요."

# 4. 받아지는지 확인 (4분)

### 【그대로 읽으세요】

> "받아지기 시작했어요. 아무것도 안 눌러도 저절로 받아져요.
>
> 그런데 **어디를 봐야 받아지는지 알 수 있는지** 알려 줄게요.
> 이걸 모르면 받아지는 중인데도 '안 되나?' 하고 딴 걸 누르게 돼요."

### 화면에 보여줄 것 — 다운로드 표시 위치 (확대 + 화살표)

> "화면 **오른쪽 위**를 보세요.
> **아래를 향한 화살표**가 생겼죠? 거기에 숫자가 나와요.
> 몇 퍼센트인지, 얼마나 남았는지요.
>
> 그 화살표를 **한 번** 누르면 자세히 보여요."

### 화면에 보여줄 것 — 다운로드 목록 펼친 상태

> "이렇게 **창의디자인캠프 설치** 라고 써 있고 막대가 차오르면
> 잘 되고 있는 거예요.
>
