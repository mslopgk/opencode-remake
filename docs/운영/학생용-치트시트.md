# 우리 캠페인 만들기 — 도우미 사용법

## 시작하는 법

캠프 당일 아침에 바탕화면의 **`캠프 시작`** 을 두 번 누르면 됩니다.
아무것도 입력하지 않아도 돼요. 앱이 열리면 도우미에게 **그냥 인사**해 보세요.

## 뭘 해야 할지 모를 때

**`/도와줘`** 라고 쓰세요. 지금 할 일을 알려 줍니다.

## 쓸 수 있는 말

| 이렇게 쓰면 | 이런 일이 생겨요 |
|---|---|
| `/도와줘` | 지금 무엇을 하면 좋은지 알려 줘요 |
| `/시작` | 조 번호, 팀 이름, 캠페인 주제를 정해요 |
| `/아이디어` | 어떤 캠페인을 할지 같이 생각해요 |
| `/포스터` | 그림을 만들어 줘요 |
| `/영상` | 짧은 영상을 만들어 줘요 |
| `/슬라이드추가` | 발표자료에 새 장을 넣어요 |
| `/보여줘` | 지금까지 만든 발표자료를 열어서 봐요 |
| `/발표연습` | 발표 대본을 만들고 연습해요 |
| `/합쳐줘` | 친구들이 만든 슬라이드를 하나로 합쳐요 (팀장만) |
| `/제출` | 다 만든 발표자료를 제출용으로 묶어요 |
| `/올리기` | 발표자료를 인터넷 주소로 만들어요 |

## 그냥 말해도 돼요 (이게 제일 편해요)

위에 있는 `/` 로 시작하는 말을 **안 써도 됩니다.** 그냥 말하면 알아들어요.

- "바다에 쓰레기 떠 있는 그림 만들어 줘"
- "세 번째 장 글씨 좀 줄여 줘"
- "발표자료 색을 초록색으로 바꿔 줘"

## 발표자료 보는 법 — 두 가지

**쉬운 쪽:** 바탕화면의 **`발표자료 보기`** 를 두 번 누르세요. 그게 제일 빨라요.

**말로 하는 쪽:** 도우미에게 **"보여줘"** 라고 말해도 열어 줘요.

발표자료가 열리면 **→ 키**를 눌러 다음 장으로, **← 키**를 눌러 앞 장으로.

## 알아두면 좋아요

- 답이 나오는 데 **15초쯤** 걸려요. 기다려 주세요. 여러 번 누르지 않아도 돼요.
- 그림은 마음에 안 들면 **몇 번이든 다시** 만들 수 있어요.
- 발표자료에는 **이름 대신 팀 이름**을 넣어요.
