## ⚠ 강사·운영진이 먼저 확인할 것 — 인터넷 속도

**이게 이 강의의 성패를 결정합니다.**

설치 파일은 **362MB** 이고, 63명이 동시에 받으면 **22.3GB** 가 흐릅니다.

| 캠프장 회선 | 63명 다 받는 데 걸리는 시간 |
|---|---|
| 100 Mbps | **약 51분** ← 강의가 불가능합니다 |
| 300 Mbps | 약 17분 ← 빠듯합니다 |
| **500 Mbps** | **약 10분** ← 이 대본대로 가능 |
| 1 Gbps | 약 5분 ← 여유 |

**캠프 전에 캠프장 회선 속도를 반드시 확인하십시오.**

### 300 Mbps 이하이면 반드시 나눠 받습니다

한 번에 다 받게 하지 말고 **조 단위로 순서를 정해** 받습니다.

```
1~5조   (20명)  → 먼저 받기 시작
6~10조  (20명)  → 3분 뒤
11~15조 (20명)  → 6분 뒤
```

기다리는 조는 그동안 캠페인 주제를 이야기하게 합니다.
대본의 0:11~0:20 "받는 동안" 절을 그 시간에 씁니다.

### 반드시 준비할 백업 — USB

**USB 메모리 몇 개에 설치 파일을 담아 오십시오.**
인터넷이 느리거나 끊긴 학생에게 조교가 바로 꽂아 줍니다.
USB 3.0 이면 한 대에 10초면 끝납니다.

담을 것: `camp2026-setup.exe` 파일 하나만.

## 강사가 먼저 알 것 (읽지 말고 알아두기)

### 오늘 가장 어려운 단계는 "주소 입력" 입니다

`camp.kodekorea.kr` 을 초등학교 5학년이 직접 치는 것이 이 강의의 벽입니다.
영어 알파벳 17자와 점 두 개를 정확히 써야 합니다.

**그리고 아주 중요한 함정이 있습니다.**

이 주소는 **검색으로 찾을 수 없습니다.** 검색엔진이 못 찾게 막아 놓았기
때문입니다(설치 파일 안에 열쇠가 있어서 일부러 그렇게 했습니다).

그런데 이 나이 아이들은 **검색창에 주소를 칩니다.** 그러면 아무것도
안 나오고 "안 돼요" 가 됩니다.

**그래서 "주소창"과 "검색창"을 구분해 가르치는 데 시간을 씁니다.**
0:04~0:11 구간이 그것입니다. 절대 서두르지 마십시오.

### 준비물

- [ ] 칠판이나 큰 화면에 **`camp.kodekorea.kr`** 을 **아주 크게** 써 두기
- [ ] 강사 화면을 프로젝터로 띄워 두기 (주소창 위치를 짚어 줄 수 있게)
- [ ] USB 백업 (위 참고)
- [ ] 조교 3명 이상

### 쓰지 않는 말

프로그램·터미널·명령어·파일 경로·설치 마법사 — 쓰지 않습니다.

| 이렇게 부릅니다 | (실제로는) |
|---|---|
| 인터넷 | 웹 브라우저 |
| 위쪽 긴 칸 | 주소창 |
| 받기 | 다운로드 |
| 파란 화면 | SmartScreen 경고 |

> 동그란 파란색 그림이나, 무지개 색 동그라미요.
>
> 선생님 화면에서 볼까요? 이거요. 이게 인터넷이에요.
>
> 그걸 **두 번** 누르세요. 딸깍딸깍.

| 인터넷이 여러 개 열림 | 하나만 남기고 닫아 준다 |
| 처음 열어서 설정 화면이 나옴 | 조교가 넘겨 준다 |

### 【열린 뒤】

> 다음이 오늘 제일 중요한 부분이에요. 잘 들어 주세요."

## 0:04 ~ 0:11 · 주소 입력 ★ 가장 어려움

**절대 서두르지 마십시오.** 여기서 막히면 뒤가 전부 밀립니다.

### 1단계 — 주소창과 검색창 구분 (2분)

### 【그대로 읽으세요】

> "화면을 보면 글씨 쓸 수 있는 칸이 **두 개** 보일 수 있어요.
>
> 하나는 **맨 위**에 있는 길쭉한 칸이에요. 이게 **주소창**이에요.
> 또 하나는 화면 **가운데**에 있는 동그란 칸이에요. 이건 **검색창**이에요.
>
> 오늘은 **맨 위에 있는 주소창**을 써야 해요.
> 가운데 검색창에 쓰면 **아무것도 안 나와요.**
>
> 왜냐하면 우리 프로그램은 **비밀 주소**라서 검색으로는 못 찾아요.
> 우리 캠프 학생들만 쓰는 주소니까요.
>
> 그러니까 꼭 **맨 위, 제일 위에 있는 긴 칸** 이에요.
> 선생님 화면에서 짚어 볼게요. 여기요. 맨 위."

### 확인 — 손가락으로 짚게 한다

> "자, 다들 손가락으로 자기 화면의 **맨 위 긴 칸**을 짚어 보세요.
> 조교 선생님들이 돌아보실 거예요."

**조교 전원이 이때 돌면서 학생이 짚은 곳이 맞는지 확인합니다.**
가운데 검색창을 짚은 학생을 바로잡아 줍니다.

### 2단계 — 주소 치기 (4분)

### 【그대로 읽으세요】

> "짚은 그 칸을 **한 번 콕** 누르세요. 그러면 글씨를 쓸 수 있어요.
> 안에 뭐가 써 있으면 그냥 무시하고 쓰면 지워져요.
>
> 이제 칠판을 보세요. 이렇게 써 있죠?
>
>     camp.kodekorea.kr
>
> 천천히 같이 쳐 볼게요. **영어**로 써요. 한글 아니에요.
> 한글이 나오면 **한/영** 키를 한 번 누르세요.
>
> 자, 하나씩 갈게요.
>
> **c - a - m - p**  … 캠프예요. 쳤어요?
> 그다음 **점**. 마침표요. 쉼표 아니고 점.
> **k - o - d - e**  … 코드
> **k - o - r - e - a**  … 코리아
> 그다음 또 **점**.
> **k - r**  … 케이알
>
> 다 됐어요? 칠판과 똑같은지 한 번 더 봐 주세요.
> `camp` 점 `kodekorea` 점 `kr`"

### 확인 — 엔터 전에 멈춘다

> "아직 엔터 누르지 마세요!
> 조교 선생님들이 돌면서 확인해 주실 거예요.
> 틀린 사람은 고쳐 줄 거예요."

**조교 전원이 60대를 빠르게 확인합니다.** 이 확인을 건너뛰면
잘못 친 학생이 "안 돼요" 를 외치며 흐름이 깨집니다.

### 3단계 — 엔터 (1분)

### 【그대로 읽으세요】

> "다 확인됐으면, 이제 **엔터**를 누르세요.
> 키보드 오른쪽에 있는 꺾인 화살표 큰 키요.
>
> 한 번만! 여러 번 누르면 여러 개 받아져요."

### 사고 대처

| 증상 | 대처 |
|---|---|
| 검색 결과 화면이 나옴 | 검색창에 쓴 것. **주소창에 다시** |
| "찾을 수 없습니다" | 주소 오타. 조교가 대신 쳐 준다 |
| 한글로 써짐 | **한/영** 키 |
| 점이 쉼표로 됨 | 조교가 고쳐 준다 |
| 대문자로 써짐 | 괜찮다. 대소문자는 상관없다 |
| 아무 반응 없음 | 엔터를 안 눌렀다 |

## 0:11 ~ 0:20 · 받는 동안

### 【그대로 읽으세요】

> "짜잔! 뭔가 받아지기 시작했죠?
> 아무것도 안 눌러도 저절로 받아져요. 그게 맞아요.
>
> 이 파일은 **꽤 커요.** 그래서 시간이 좀 걸려요.
> **5분에서 10분** 정도요.
>
> 받는 동안 **아무것도 누르지 마세요.** 특히 인터넷 창을 닫지 마세요.
> 닫으면 처음부터 다시 받아야 해요."

### 어디를 봐야 하는지 알려주기

> "받는 게 어디 보이냐면요.
> 화면 **오른쪽 위**에 아래를 향한 화살표가 생겨요.
> 거기에 몇 퍼센트인지 나와요.
>
> 또는 화면 **아래쪽**에 막대가 생기기도 해요.
> 어느 쪽이든 괜찮아요. 숫자가 올라가면 되는 거예요."

### 【이 시간에 하는 활동 — 캠페인 주제 이야기】

기다리는 시간을 비워 두면 아이들이 딴 걸 누릅니다. 붙잡아 둡니다.

> "받는 동안 우리 조끼리 이야기해 볼까요?
> 조끼리 모여서 이런 걸 얘기해 보세요.
>
> 하나, 우리 주변에서 **안타까운 일**이 뭐가 있을까?
> 학교에서, 동네에서, 뉴스에서 본 것 중에요.
>
> 둘, 그중에 **우리가 뭔가 할 수 있는 것**은 뭘까?
>
> 셋, 우리 팀 이름은 뭐로 할까?
>
> 3분 뒤에 몇 조 발표 들어볼게요."

**3분 뒤 2~3개 조를 지목해 한 문장씩 발표시킵니다.**
그러면 나머지 시간도 집중이 유지됩니다.

### 조교가 이 시간에 하는 일

- 받기가 시작 안 된 학생 찾아내기 (화면 오른쪽 위 확인)
- 느린 학생에게 **USB로 바로 넣어 주기**
- 인터넷 창을 닫은 학생 다시 시작시키기

### 사고 대처

| 증상 | 대처 |
|---|---|
| 받기가 시작 안 됨 | 주소를 다시 확인. 안 되면 USB |
| 중간에 멈춤 | 주소창에 다시 엔터. 이어서 받아진다 |
| 인터넷 창을 닫음 | 다시 열고 주소 다시 (조교가 대신) |
| "위험한 파일" 경고 | **유지** 또는 **계속**을 누르게 한다 |
| 10분 넘게 안 끝남 | USB로 전환 |

> 이미 깔린 건 건너뛰니까 빠르게 끝나요.
> 둘, 그다음 **점검** 을 다시 누르세요.
>

### 사고 대처

| 증상 | 대처 |
|---|---|
| 캠프 설정 빨간불 | 설치 다시 실행 → 점검 다시 |

| 그림 만들기 빨간불 | 인터넷 확인 → 점검 다시 |

| 점검 창이 안 열림 | 조교가 대신 실행 |
