# 창의디자인캠프 opencode 개조판 — 설계

작성일: 2026-08-21
대상 행사: 2026 영남·제주권역 창의디자인캠프

## 1. 배경

영남·제주권역 창의디자인캠프(주제: **디자인씽킹 × 생성형 AI**)에 참가하는
초등 5학년 ~ 중등 1학년 60명이, 1박2일 동안 "과학 캠페인" 발표자료를 직접 만든다.

이 나이대는 터미널·개발환경 경험이 없고, 정미 제작시간은 5시간뿐이다.
그래서 범용 AI 코딩 에이전트(opencode)를 **이 캠프 전용으로 개조한 배포판**을 만들어
학생이 도구 사용법을 배우는 데 시간을 쓰지 않고 바로 산출물을 만들게 한다.

## 2. 이번 범위

**이번 구현 대상: opencode 개조판 코어**

- opencode 설정 프리셋 (`opencode.json`, `tui.json`)
- 캠프 전역 규칙 (`AGENTS.md`)
- 캠프 전용 에이전트 4종
- 한국어 슬래시 명령어 10종
- 캠프 전용 스킬 3종
- 팀 프로젝트 템플릿 (웹슬라이드 발표자료)

**이번 범위에서 제외 (다음 단계로 분리)**

| 항목 | 사유 |
|---|---|
| Windows 인스톨러 / 런처 | 개조판이 완성된 뒤 그것을 포장하는 일. 순서상 다음 |
| 자체 정적 배포 (서브도메인) | 캠프 필수 아님. 개조판 완성 후 착수 |
| 자체 Git 호스팅 | 캠프에 불필요. 다음 회차용 |
| macOS 지원 | Windows 우선 결정 |

**opencode 소스는 포크하지 않는다.** 필요한 개조가 전부 설정·에이전트·명령어·스킬 층에서
가능함을 문서로 확인했다. 포크하지 않으므로 opencode 업데이트에 깨지지 않고,
남은 기간(24일)에 확실히 들어간다.

## 3. 목표와 비목표

### 목표

1. 초5 학생이 **어른 도움 없이 20분 안에** 슬라이드 3장 + AI 생성 이미지 1장이 들어간
   발표자료를 만든다.
2. 학생은 코드를 볼 필요가 없다. 대화만으로 산출물이 나온다.
3. 도구가 캠프의 목적·주제·트랙·발표형식·남은 시간을 **미리 알고 있다.**
   학생이 배경 설명을 하지 않아도 된다.
4. 15팀 전원이 5시간 안에 발표 가능한 산출물에 도달한다 (완성도 하한선 보장).

### 비목표

- 학생에게 프로그래밍을 가르치는 것
- 범용 개발도구로서의 유연성 유지 (오히려 의도적으로 좁힌다)
- 결과물의 기술적 정교함

## 4. 산출물 형태 결정

**정적 HTML + assets 폴더.** React·빌드 도구를 쓰지 않는다.

React가 기술적으로 불가능해서가 아니라 **실패율 때문이다.** `npm install`(60대 각각 수백 MB),
빌드 에러, 포트 충돌, `node_modules` 파손 중 하나만 터져도 그 팀은 5시간 안에
발표자료를 못 만든다. 정적 HTML은 더블클릭하면 무조건 열린다.

AI가 코드를 작성하므로 표현력 손실은 거의 없다 — 슬라이드 전환, 애니메이션, 차트가
모두 순수 JS로 가능하다.

`index.html` 한 파일 + `assets/` 폴더 구성. 영상을 base64로 인라인하면 파일이
수백 MB가 되므로 단일 파일은 강제하지 않는다. 제출 시 zip으로 묶는다.

## 5. 개인정보 설계

참가자가 **만 14세 미만**이므로 개인정보를 아예 수집하지 않는다.

- 학생 계정·실명·이메일·학교명을 어디에도 저장하지 않는다
- 식별자는 **조번호 + 팀명**만 사용 (`03조_지구지킴이`)
- 산출물·발표자료·파일명·폴더명에 실명이 들어가지 않도록 에이전트 규칙으로 강제
- 학생이 실명을 입력하려 하면 에이전트가 팀명으로 대체하도록 유도

이렇게 하면 법정대리인 동의·보관·파기 의무가 발생하지 않는다.

## 6. 구조

```
camp-preset/
├─ opencode.json              # 프로바이더, MCP, 권한, 지시문
├─ tui.json                   # 테마, 키바인딩
├─ AGENTS.md                  # 캠프 전역 규칙 (가장 중요한 파일)
├─ agents/
│  ├─ 도우미.md               # primary — 학생과 대화하는 기본 에이전트
│  ├─ 아이디어.md             # subagent — HMW, 브레인스토밍
│  ├─ 디자이너.md             # subagent — 슬라이드 구성·시각디자인
│  └─ 미디어.md               # subagent — 이미지·음원·영상 생성 전담
├─ commands/
│  ├─ 시작.md                 # 팀 정보 등록, 컨셉 인터뷰 시작
│  ├─ 아이디어.md             # How Might We 진행
│  ├─ 포스터.md               # 캠페인 포스터 생성
│  ├─ 음악.md                 # 캠페인 BGM·로고송 생성
│  ├─ 영상.md                 # 짧은 캠페인 영상 생성
│  ├─ 슬라이드추가.md         # 발표자료에 장 추가
│  ├─ 보여줘.md               # 브라우저로 발표자료 열기
│  ├─ 발표연습.md             # 발표 대본 생성·리허설
│  ├─ 제출.md                 # zip 묶기
│  └─ 도와줘.md               # 지금 뭘 할지 안내
├─ skills/
│  ├─ 캠페인-기획/SKILL.md
│  ├─ 슬라이드-만들기/SKILL.md
│  └─ 발표대본/SKILL.md
└─ template/                  # 팀 프로젝트 템플릿
   ├─ index.html              # 웹슬라이드 발표자료
   ├─ assets/                 # AI 생성물 저장 위치
   └─ 우리팀.md               # 팀명·컨셉·진행상황 기록 (에이전트가 읽고 씀)
```

설치 시 `camp-preset/` 내용이 `~/.config/opencode/` 로,
`template/` 은 팀 폴더로 복사된다.

### opencode 설정 매핑 (문서 확인 완료)

| 개조 대상 | 실제 경로 |
|---|---|
| 전역 규칙 | `~/.config/opencode/AGENTS.md` |
| 에이전트 | `~/.config/opencode/agents/*.md` (frontmatter: description, mode, model, temperature, permission) |
| 슬래시 명령어 | `~/.config/opencode/commands/*.md` (`$ARGUMENTS`, `` !`cmd` ``, `@file` 지원) |
| 스킬 | `~/.config/opencode/skills/<name>/SKILL.md` (frontmatter: name, description) |
| 프로바이더 | `opencode.json` → `provider` (`{env:...}` 치환 지원) |
| MCP | `opencode.json` → `mcp` (local: command/environment, remote: url/headers) |
| 툴 잠금 | `opencode.json` → `permission`, `tools` |
| 테마·키바인딩 | `tui.json` |
| 추가 지시문 | `opencode.json` → `instructions` (glob 지원) |

## 7. 핵심 설계 결정

### 7.1 학생은 코드를 보지 않는다

`도우미` 에이전트는 코드·파일·경로를 학생에게 언급하지 않는다.
대화는 항상 "무엇을 만들까"로 진행하고, 코드 작성은 배경에서 처리한다.
학생이 결과를 확인하는 유일한 통로는 `/보여줘`(브라우저로 열기)다.

### 7.2 한 번에 한 질문

초5 대상이므로 에이전트는 절대 여러 질문을 한 번에 하지 않는다.
선택지는 최대 3개, 각 선택지는 한 줄. 전문용어 금지.

### 7.3 모든 인터페이스가 한국어

명령어 이름, 에이전트 이름, 응답이 전부 한국어.
학생이 영어 명령어를 외울 필요가 없다.

### 7.4 도구가 캠프를 미리 안다

`AGENTS.md`에 캠프 주제·목적·두 트랙·과학 캠페인 개념·발표 형식·타임라인·
말투 규칙·안전 규칙을 모두 담는다. 학생이 "우리 이런 대회 나왔는데"를
설명할 필요가 없고, 에이전트가 먼저 "우리 팀은 어느 트랙이야?"부터 묻는다.

### 7.5 시간을 인식한다

에이전트가 캠프 타임라인을 알고 있어서 "이제 제작②시간이니 슬라이드를
마무리하자" 같은 진행 관리를 한다. 5시간 안에 완성시키는 압박을
사람 멘토 15명이 아니라 도구가 나눠 진다.

### 7.6 완성도 하한선을 템플릿으로 보장

발표자료 골격(표지 / 발견한 문제 / How Might We / 캠페인 컨셉 /
우리가 만든 것 / 실천 제안 / 팀 소개)을 템플릿에 고정하고,
색 테마 4종을 프리셋으로 넣는다. 학생이 CSS를 만지지 않아도
모든 팀이 보기 좋은 결과에 도달한다.

### 7.7 미디어 생성은 전담 에이전트가 번역해서 호출

학생은 한국어로 "바다에 쓰레기 떠 있는 슬픈 그림" 이라고 말한다.
`미디어` 에이전트가 이를 영어 프롬프트로 바꿔 Higgsfield에 넘긴다.
학생이 프롬프트 엔지니어링을 배울 필요가 없다.

### 7.8 위험한 동작 잠금

`permission`/`tools` 로 파일 삭제·시스템 명령·임의 웹 접근을 제한한다.
학생이 실수로 프로젝트를 날리는 경로를 없앤다.

단 `bash`를 전면 차단하면 `/보여줘`(브라우저로 열기)와 `/제출`(zip 묶기)이
동작하지 않는다. 따라서 전면 차단이 아니라 **삭제성·시스템성 명령만 차단**하고
필요한 명령은 허용하는 방향으로 설계한다.
opencode의 `permission.bash` 가 명령 단위 패턴 허용을 지원하는지는
문서에 없으므로 W1 검증 항목이다. 지원하지 않으면 대안은
`bash` 를 `"ask"` 로 두고 위험 명령을 에이전트 규칙으로 금지하는 것이다.

### 7.9 모델 역할 분리

- **DeepSeek** — 텍스트·코드 (슬라이드 생성, 대본, 기획 대화)
- **Higgsfield** — 이미지·음원·영상

DeepSeek은 텍스트 전용이므로 미디어 생성은 반드시 별도 경로가 필요하다.
API 키는 배포판에 내장한다 (결정됨). DeepSeek 콘솔에서 이 키 전용으로
잔액·한도를 분리해 최악의 경우 피해 상한을 묶는다.

## 8. Higgsfield 실측 결과 (2026-08-21 확인 완료)

### 접근 경로 — MCP가 아니라 CLI

Higgsfield는 MCP 서버가 아니라 **`higgsfield` CLI**다 (`higgs`, `hf` 별칭).
설치: `curl -fsSL https://raw.githubusercontent.com/higgsfield-ai/cli/main/install.sh | sh`
(현재 환경에는 npm 경로에 설치되어 있음)

opencode에서는 MCP가 아니라 **bash 툴 + 스킬**로 호출한다.
`미디어` 에이전트가 CLI 명령을 조립해 실행하는 구조.

### 인증 — 사전 심기 가능 (검증됨)

OAuth 2.0 PKCE 브라우저 로그인 방식이지만, 자격증명이 로컬 파일에 저장된다.

| 파일 | 내용 |
|---|---|
| `~/.config/higgsfield/credentials.json` | `auth_version`, `access_token`, **`refresh_token`**, `expires_at`, `token_type`, `scope` |
| `~/.config/higgsfield/config.json` | `workspace_id` |

**`refresh_token`이 있으므로 이 두 파일을 배포판에 심으면 학생 노트북에서
대화형 로그인 없이 동작한다.** 액세스 토큰이 만료돼도 CLI가 자동 갱신한다.
"키를 인스톨러에 박는다"는 방침이 Higgsfield에도 적용 가능하다.

주의: 이 파일은 계정 전체 권한을 가진 자격증명이다. DeepSeek 키와 동일하게
유출 리스크를 감수하는 결정이며, 사고 시 대응은 `higgsfield auth logout` 또는
계정 측 세션 무효화다.

### 크레딧 예산 — 모델 기본값을 비용 기준으로 고정해야 한다

15팀이 자유롭게 쓰면 1360 크레딧은 **첫 1~2시간에 소진된다.**
`gpt_image_2`(7) 기본값으로 아이들이 포스터를 20번 다시 뽑으면 팀당 140크레딧,
15팀이면 2100으로 이미 초과다. 영상은 더 심하다.

따라서 모델 기본값을 다음과 같이 고정한다:

| 상황 | 모델 | 근거 |
|---|---|---|

잔액 1,360 대비 여유가 250뿐이다. **크레딧 충전을 권고한다** —
사전 온라인교육(9/14~18) 때 60명이 연습으로 쓰는 분량이 예산에 아직 없고,
당일 재시도 폭증 여지도 없다. 최소 2배(2,500~3,000) 확보를 권장한다.

## 9. 남은 W1 실측 검증 항목

설계 가정 중 문서로 확인되지 않아 실제로 돌려봐야 하는 것들:

1. **DeepSeek 모델 ID와 한국어 품질** — 실제 사용 가능한 모델 ID 확정,
   초등학생 대상 한국어 응답 품질, 응답 속도, rate limit
2. **60명 동시 사용 한계** — DeepSeek·Higgsfield 양쪽의 동시성 (8절 참조)
3. **한글 경로 동작** — Windows 사용자명이 한글일 때 opencode 설정 경로가
   정상 동작하는지
4. **opencode 버전 고정** — 특정 버전으로 고정했을 때 프리셋이 동작하는지
5. **Nerd Font 없을 때 TUI 깨짐 정도** — 폰트 동반 설치 필요성 확인
6. **`permission.bash` 패턴 허용 지원 여부** — 명령 단위 allowlist가 가능한지 (7.8절 참조)
7. **`%ProgramData%\opencode` 관리자 설정** — 문서화되지 않아 소스 확인 필요
   (이번 범위 필수는 아니나 학생이 설정을 깨뜨리는 것을 막는 데 유용)
