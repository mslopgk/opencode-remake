# 학생용 프로그램 — 제한·추가·커스텀 기능 명세

기준일: 2026-08-24
대상: 2026 영남·제주권역 창의디자인캠프 학생 60명 (초5~중1)
베이스: opencode 1.18.20 (**소스 포크 없음**)

이 문서는 "원본 opencode에서 무엇을 막았고, 무엇을 새로 넣었고, 무엇을 바꿨는지"를
구현 위치와 함께 정리한 것이다. 각 항목은 실제 파일에서 확인한 값이다.

---

## 0. 구현 원칙 세 가지

이 세 가지가 나머지 모든 결정의 근거다.

| 원칙 | 뜻 | 왜 |
|---|---|---|
| **포크하지 않는다** | opencode가 원래 읽는 설정 경로에만 파일을 심는다 | opencode 업데이트에 깨지지 않고, 남은 기간(24일)에 확실히 들어간다 |
| **기계적인 일은 스크립트가 한다** | 크레딧 예산, 슬라이드 합치기, 팀 폴더 생성은 프롬프트가 아니라 코드 | 프롬프트는 지켜질 수도 안 지켜질 수도 있지만 스크립트는 반드시 지킨다 |
| **점검은 숫자로 한다** | "설치된 것 같다"가 아니라 에이전트 4개·명령어 11개를 세어 확정 | 초록불이 켜져도 학생이 못 쓰는 상태가 실제로 있었다 |

구현 층은 넷이다.

```
층 1  ~/.config/opencode/          프리셋 (프롬프트 694줄)
층 2  팀 폴더/                      발표자료 템플릿 (117줄)
층 3  %LOCALAPPDATA%\Programs\camp-tools\   헬퍼 스크립트 (268줄)
층 4  dist/                        인스톨러·GUI (PowerShell 1,599줄)
```

## 1. 제한한 기능

### 1.1 opencode 설정으로 막은 것

`camp-preset/opencode.json`

| 설정 | 값 | 막는 것 | 이유 |
|---|---|---|---|
| `webfetch` | `deny` | 임의 웹 접근 | 학생이 아무 사이트나 읽어오는 경로를 없앤다 |
| `share` | `disabled` | 세션 공유 링크 생성 | 대화 내용이 외부 URL로 나가는 것을 원천 차단 (만 14세 미만) |
| `autoupdate` | `false` | 자동 버전 갱신 | 캠프 중 버전이 바뀌면 프리셋이 깨질 수 있다 |
| `model` / `small_model` | `deepseek/deepseek-v4-flash` 고정 | 다른 모델 선택 | `deepseek-chat`은 말투가 딱딱하고 SNS 같은 부적절 제안이 나왔다(실측) |
| `default_agent` | `도우미` | 기본 에이전트가 `build`로 열리는 것 | 학생이 개발자용 에이전트를 만나지 않게 한다 |

`edit`과 `bash`는 `allow`로 둔다. 막으면 `/보여줘`(브라우저 열기)·`/제출`(zip)·
그림 만들기가 전부 동작하지 않는다. 대신 위험 동작은 아래 프롬프트 규칙으로 막았다.

### 1.2 학생에게 보이지 않게 막은 것

`camp-preset/AGENTS.md` · `camp-preset/agent/도우미.md`

**금지 용어 15개** — 학생에게 절대 쓰지 않는다:

> 터미널, 커맨드, 명령어, 파일 경로, 디렉토리, 코드, 커밋, HTML, CSS,
> 자바스크립트, API, 프롬프트, 모델, 크레딧, 에이전트

`도우미` 에이전트는 추가로:

- 코드를 학생에게 보여주지 않는다
- 파일 이름·폴더 위치를 말하지 않는다
- 무엇을 만들었는지 설명할 때 기술 용어를 쓰지 않는다
  ("HTML 파일을 수정했어요" ✕ → "발표자료에 새 장을 넣었어요" ○)
- 다른 에이전트에게 일을 맡겼다는 말을 하지 않는다 (결과만 보여준다)

### 1.3 개인정보 — 아예 수집하지 않는다

참가자가 **만 14세 미만**이라 동의·보관·파기 의무가 생기지 않도록
수집 자체를 차단했다.

| 규칙 | 구현 |
|---|---|
| 이름·학교·학년·반·나이·주소·전화·이메일을 **묻지 않는다** | `AGENTS.md` 개인정보 규칙 |
| 학생이 스스로 이름을 말해도 **어디에도 적지 않는다** | 같음 (발표자료·파일명·폴더명·그림 요청 전부) |
| 식별자는 **조 번호 + 팀 이름**만 (`03조_지구지킴이`) | `new-team.sh` / `lib-team.ps1`이 이 형식만 만든다 |
| 런처가 학생 이름을 **입력받지 않는다** | `gui-launcher.ps1` — 입력칸이 조번호·팀명 둘뿐 |
| 발표 대본에 이름 대신 `1번 친구` | `skills/presentation-script` |
| 사람 얼굴을 만들지 않는다 | `agent/미디어.md` — 실루엣·뒷모습으로 대체 |

**검증됨**: E2E에서 "내 이름은 김하늘이야, 발표자료에 넣어줘"를 실제로 요청했고
`index.html`과 `우리팀.md` 양쪽에 들어가지 않는 것을 확인했다.

### 1.4 안전 규칙

`camp-preset/AGENTS.md`

- 무섭거나 폭력적이거나 슬픔이 지나친 그림·영상은 만들지 않는다
- 실제 인물·실제 상표·실제 회사 이름을 그림에 넣지 않는다
- SNS·인터넷에 올리자는 제안을 하지 않는다
- 캠프와 관계없는 요청은 부드럽게 캠페인 만들기로 되돌린다

`agent/미디어.md`에 그림 요청 규칙이 추가로 있다 — 밝고 단순한 스타일,
그림 안에 글자 넣지 않기(대표 이미지만 예외).

### 1.5 비용 — 프롬프트가 아니라 스크립트가 강제

`scripts/camp-media.sh` (→ `camp-tools/camp-media.sh`)

| 종류 | 모델 | 횟수 제한 | 강제 방식 |
|---|---|---|---|
| 그림 (기본) | `nano_banana_2_lite` | 없음 | — |
| 대표 (표지용) | `gpt_image_2` | **팀당 2회** | `<팀폴더>/.camp/counts`에 카운터, 초과 시 `exit 3` |
| 음악 | `seed_audio` | 없음 | — |
| 영상 | `seedance_2_0` | **팀당 2회** | 초과 시 `exit 2` |

설계 포인트:

- **생성 전에 막는다** — 호출한 뒤 되돌리는 게 아니라 카운터를 먼저 본다
- **실패는 카운터를 늘리지 않는다** — 다운로드까지 성공해야 카운트
- **에이전트가 `higgsfield`를 직접 부르는 것을 금지** — 직접 부르면 제한이 안 걸린다.
  `agent/미디어.md`와 `skills/media-generation`에 명시
- 카운터는 팀 폴더별로 독립 (다른 팀에 영향 없음)

> 이 제한은 Higgsfield 크레딧이 빠듯해서 넣은 것이다.
> 더 싼 제공자로 옮기면 이미지 쪽은 풀 수 있다.

### 1.6 산출물에 못 넣게 막은 것

`camp-preset/skills/web-slides/SKILL.md`

| 금지 | 이유 |
|---|---|
| 외부 URL — CDN·웹폰트·외부 스크립트 | **캠프장 인터넷이 끊겨도 발표가 되어야 한다** |
| 빌드 도구 — 패키지 설치·번들러·프레임워크 | `npm install` 하나가 터지면 그 팀은 5시간 안에 발표자료를 못 만든다 |
| 슬라이드 전환 스크립트를 새로 만들기 | 이미 있는 것을 쓴다 (깨질 여지를 없앤다) |
| 절대경로로 그림 참조 | 다른 컴퓨터에서 안 보인다 |
| 개별 요소에 색 직접 지정 | 테마가 깨진다. `data-theme`만 바꾼다 |
| `index.html`을 직접 편집해 합치기 | 느리고 결과가 들쭉날쭉하다(실측 10분 초과). `merge-slides.sh`가 한다 |

**검증됨**: E2E에서 슬라이드를 추가한 뒤에도 `https://`·`cdn`·`npm`이
`index.html`에 들어가지 않는 것을 확인했다.

## 2. 추가한 기능

### 2.1 에이전트 4종 — `camp-preset/agent/`

| 이름 | mode | temp | 역할 |
|---|---|---|---|
| `도우미` | primary | 0.7 | 학생과 직접 대화. 나머지에 일을 위임 |
| `아이디어` | subagent | 0.9 | How Might We·브레인스토밍 (발산이라 온도 높임) |
| `디자이너` | subagent | 0.4 | 발표자료 편집 (정확성이라 온도 낮춤) |
| `미디어` | subagent | 0.5 | 그림·음악·영상 생성 전담 |

**왜 쪼갰나**: `도우미`에는 "코드·명령어를 학생에게 말하지 마라"가 박혀 있다.
그러면 정작 명령을 실행해야 할 때 회피한다. 그래서 실행 담당을 분리했다.
학생은 `도우미`만 상대하고 나머지는 뒤에서 돕는다.

`미디어`는 학생의 한국어 요청을 **영어 프롬프트로 번역**해서 넘긴다.
학생이 프롬프트 엔지니어링을 배울 필요가 없다.

### 2.2 한국어 슬래시 명령어 11종 — `camp-preset/command/`

| 명령어 | 담당 | 하는 일 |
|---|---|---|
| `/도와줘` | 도우미 | **다음 할 일 하나만** 제안 + 구체적 칭찬 |
| `/시작` | 아이디어 | 조번호·팀명·트랙·캠페인 주제 정하기 |
| `/아이디어` | 아이디어 | 문제 찾기 → How Might We → 캠페인 이름 |
| `/포스터` | 미디어 | 그림 생성 (기본은 1크레딧 모델) |
| `/음악` | 미디어 | 배경음악·로고송 |
| `/영상` | 미디어 | 짧은 캠페인 영상 (팀당 2번 안내 포함) |
| `/슬라이드추가` | 디자이너 | 발표자료에 장 추가 |
| `/합쳐줘` | 디자이너 | 친구들 슬라이드를 하나로 조립 (팀장용) |
| `/보여줘` | 도우미 | 브라우저로 발표자료 열기 |
| `/발표연습` | 도우미 | 4명 분담 2분 대본 생성 |
| `/제출` | 도우미 | 제출용 zip + 사전 점검 |

명령어 이름·설명·응답이 **전부 한국어**다. 학생이 영어를 외울 필요가 없다.

`/보여줘`·`/제출`·`/합쳐줘`는 **셸 주입(`` !`cmd` ``)** 을 쓴다.
LLM 판단에 맡기지 않고 명령이 먼저 실행되고 모델은 결과만 전한다.

### 2.3 스킬 4종 — `camp-preset/skills/`

필요할 때만 로드되므로 항상 읽는 토큰을 아낀다.

| 스킬 | 내용 |
|---|---|
| `campaign-planning` | 디자인씽킹 6단계를 초등학생 눈높이로. 트랙별 문제 예시 포함 |
| `web-slides` | 발표자료 구조·편집 규칙·금지 사항·테마 4종 |
| `media-generation` | `camp-media.sh` 사용법·비용 규칙·실패 대응(exit 코드별 학생 안내) |
| `presentation-script` | 4명 분담 대본 형식, 이름 대신 번호 호칭 |

스킬 이름은 ASCII, 설명은 한국어다 (opencode 규격이 `^[a-z0-9]+(-[a-z0-9]+)*$`).

### 2.4 발표자료 템플릿 — `template/`

```
팀폴더/
├─ index.html      웹슬라이드 7장 골격 + 색 테마 4종 (외부 리소스 0)
├─ slides/         팀원별 파일 (1번친구.html …)
├─ assets/         AI 생성물 저장 위치
└─ 우리팀.md       에이전트의 기억장치
```

`index.html`은 좌우 화살표·스페이스·클릭으로 넘어간다. 순수 HTML/CSS/JS라
더블클릭하면 무조건 열린다.

기본 골격: 표지 / 우리가 찾은 문제 / How Might We / 캠페인 / 우리가 만든 것 /
실천 제안 / 우리 팀. **완성도 하한선을 템플릿으로 보장**해서, CSS를 몰라도
모든 팀이 보기 좋은 결과에 도달한다.

**`우리팀.md`가 핵심이다.** 조번호·팀명·내 번호·트랙·문제·HMW·캠페인 이름·
만든 것·다음 할 일을 여기 적는다. 대화를 시작할 때 먼저 읽으므로
세션이 끊겨도 이어진다.

### 2.5 팀 협업 — `slides/` 분리 구조

4명이 각자 노트북을 쓰는데 발표자료는 팀당 하나다. 같은 `index.html`을
여러 명이 고치면 합칠 때 충돌이 나고 **초5가 충돌을 해결할 수는 없다.**

그래서 기여를 파일 단위로 나눴다.

- 학생은 `우리팀.md`의 "나는 몇 번 친구"를 보고 `slides/N번친구.html`만 고친다
- 팀장이 `/합쳐줘` → `merge-slides.sh`가 파일명 순으로 조립
- 두 번 실행해도 중복되지 않는다 (마커 사이를 걷어내고 다시 채운다)

**자체 Git이 늦어져도 USB로 `slides/` 폴더만 주고받으면 동일하게 동작한다.**

### 2.6 헬퍼 스크립트 — `scripts/` → `camp-tools/`

| 스크립트 | 역할 | 검증 |
|---|---|---|
| `camp-media.sh` | 미디어 생성 + 크레딧 강제 | 단위 테스트 22개 (mock으로 크레딧 0 소모) |
| `merge-slides.sh` + `.py` | 슬라이드 조립 | 단위 테스트 21개, 1초에 완료 |
| `new-team.sh` | 팀 폴더 생성 (bash) | 단위 테스트 15개 |
| `install-preset.sh` | 프리셋 설치 (개발자용) | 단위 테스트 10개 |

`merge-slides.py`가 `.sh`와 분리된 이유: 원래 `python - <<'PY'` 히어독으로 넘겼는데
**opencode의 bash 툴에서 python이 stdin을 기다리며 멈췄다.**
에이전트가 실행하는 스크립트는 stdin을 읽으면 안 된다.

### 2.7 배포 — `dist/`

| 구성 | 내용 |
|---|---|
| 진입점 `.exe` 3종 | `창의디자인캠프 설치` / `캠프 시작` / `점검` — 아이콘 있는 WinExe |
| 진입점 `.cmd` 3종 | 같은 일을 하는 백업 경로 (exe가 막히는 노트북용) |
| `orchestrator.ps1` | 서명된 공식 인스톨러들을 per-user·조용히 순차 실행 |
| `selfcheck.ps1` | 자체 점검 5종 |
| `launcher.ps1` | 당일 팀 폴더 생성 + 앱 등록 |
| `gui-*.ps1` | WPF 창 3종 (발표자료 ocean 테마와 같은 색) |
| `bundle/` | opencode 데스크탑 · standalone CLI · Node · Python · Git · 글꼴 (350MB) |
| `secrets/` | DeepSeek `auth.json` · Higgsfield `credentials.json`+`config.json` |

**자체 점검 5종** — "설치했는가"가 아니라 **"학생이 그 기능을 쓸 수 있는가"**:

1. 도구가 깔렸는지 — `opencode --version` = `1.18.20`
2. 캠프 설정이 들어갔는지 — `opencode serve` 후 `/agent` 4개 + `/command` 11개를 **센다**
3. 만들기 도구가 있는지 — `camp-tools/`의 스크립트 3개 존재 확인
4. AI 도우미가 연결되는지 — 실제로 한국어 응답을 받는다
5. 그림 만들기가 연결되는지 — 잔액까지 읽는다

3번이 없어서 "초록불 4개가 다 켜졌는데 학생은 그림을 만들 수 없는" 상태를
1차 E2E가 통과했다. 그래서 항목을 추가했다.

### 2.8 운영 문서 — `docs/운영/`

- `사전온라인교육-2시간.md` — 9/14~18 진행안. **설치 사고를 0으로 만드는 것이 목표**
- `학생용-치트시트.md` — A4 한 장. 명령어 11개 + "15초쯤 걸려요" 안내
- `멘토용-트러블슈팅.md` — 증상 → 정체 → 조치. 자주 생기는 순서

## 3. 커스텀한 기능 (원본 동작을 바꾼 것)

### 3.1 말투

`AGENTS.md`의 말하는 방법 8개 규칙:

1. 항상 한국어 존댓말
2. **한 번에 한 가지만** 물어본다
3. 선택지는 최대 3개, 각각 한 줄
4. 초등학교 5학년이 아는 낱말만
5. 전문용어 금지 (1.2절 목록)
6. 한 번에 보내는 답은 **5줄 이내**
7. 막혔을 때는 **다음 할 일 하나**를 콕 집어
8. 칭찬을 자주, 구체적으로

**검증됨**: 설치된 환경에서 `/도와줘`를 실행하니 기록을 읽고 스킬을 불러
"바다색을 이미 깔아 두고 팀 이름까지 바다친구로 지은 게 정말 잘했어요"라고
구체적으로 칭찬한 뒤 트랙 하나만 물었다.

### 3.2 시간을 인식한다

`AGENTS.md`에 캠프 타임라인이 들어 있다. 그래서 에이전트가
"이제 제작②시간이니 슬라이드를 마무리하자" 같은 진행 관리를 한다.
**5시간 안에 완성시키는 압박을 사람 멘토 5명이 아니라 도구가 나눠 진다.**

학생이 시간에 비해 너무 큰 것을 만들려 하면 "그건 안 돼요" 대신
"이렇게 하면 더 멋있게 끝낼 수 있어요"로 좁힌다.

### 3.3 첫 화면을 없앴다

원본 opencode 데스크탑은 열면 빈 프로젝트 목록과 "프로젝트 추가"가 보인다.
초5에게 폴더 고르기를 시키면 거기서 막힌다.

그래서 인스톨러·런처가 앱 상태 파일을 직접 손댄다 (둘 다 평문 JSON):

| 파일 | 손대는 것 |
|---|---|
| `%APPDATA%\ai.opencode.desktop\opencode.global.dat` | `server` 키 안의 `projects.local[]`에 팀 폴더 추가 |
| `%APPDATA%\ai.opencode.desktop\opencode.settings` | `firstLaunchOnboardingComplete: true` |

**앱을 열면 우리 팀 프로젝트가 이미 있고 온보딩이 없다.**
등록에 실패해도 팀 폴더 생성은 성공으로 보고하고 학생에게 폴더를 고르는
방법을 안내한다(강등).

### 3.4 기타 변경

| 항목 | 원본 | 캠프판 |
|---|---|---|
| 기본 에이전트 | `build` | `도우미` |
| 추가 지시문 | 없음 | `instructions: ["우리팀.md"]` — 팀 기록을 항상 읽는다 |
| 테마 | 기본 | `tokyonight` (발표자료 ocean 테마와 계열 맞춤) |
| 팀 폴더 위치 | 사용자 선택 | `~/창의디자인캠프/NN조_팀명/` 고정 |
| 발표 대본 | — | 4명 분담, 이름 대신 `1번 친구` |

## 5. 알려진 제약과 결정 사항

### 주최측이 확정한 것 (되돌리지 않는다)

- **API 키를 배포판에 내장한다** — 유출 리스크는 감수. 사고 시 키 삭제로 대응
- 만 14세 미만이라 **개인정보 무수집**
- 외부 서비스 계정 사용 불가 → 자체 배포·Git 호스팅은 별도 과제
- opencode **포크하지 않음**

### 짚어야 할 위험

**Higgsfield 자격증명은 폐기 수단이 없다.** `higgsfield auth`에는
`login`/`logout`/`token`뿐이고 `logout`은 로컬 파일만 지운다.
노트북 60대에 퍼진 리프레시 토큰을 무효화하는 CLI 명령이 없다.
"문제 생기면 키 삭제"가 DeepSeek 키에는 성립하지만 Higgsfield에는 성립하지 않는다.

→ 폐기 가능한 API 키를 쓰는 제공자로 옮기는 것을 검토 중이다.

### 제안서와 어긋나는 행사 사실 (미반영)

`proposal_changidesign_FINAL(수정).docx`와 비교했을 때 아직 맞추지 않은 것:

| 항목 | 제안서 | 현재 프리셋 |
|---|---|---|
| 트랙 | **4개** (지구·환경 / 일상·건강 / AI·디지털 / 우주·미래기술) | 2개 |
| 발표 시간 | 팀당 **6~8분** | 대본이 2분 기준 |
| 팀 인원 | **4~5인** | 4인 고정 |
| 팀 수 | 12~15팀 | 15팀 고정 |

플랫폼 방향과 무관하게 당일 학생에게 영향이 간다.
