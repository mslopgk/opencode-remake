# 발표자료를 멋있게

초등학교 5학년~중학교 1학년이 만들고, 강당에서 프로젝터로 발표하는 자료다.
"예쁘다"보다 **"뒤에서도 읽힌다"** 가 먼저다.

## 1. 색 — 테마만 바꾼다

`index.html` 의 `<html data-theme="...">` 값만 바꾼다.

| 값 | 느낌 | 어울리는 주제 |
|---|---|---|
| `ocean` | 바다·파랑 | 해양 플라스틱, 물, 기후 |
| `forest` | 숲·초록 | 환경 보호, 생태, 급식 |
| `sunset` | 노을·주황 | 에너지, 건강, 따뜻한 메시지 |
| `night` | 밤·보라 | 우주, AI·디지털, 미래 |

**개별 요소에 색을 직접 넣지 않는다.** 테마가 깨지고, 프로젝터에서 글자가
안 보이는 사고가 생긴다. 색을 더 쓰고 싶으면 테마의 강조색(`var(--accent)`)을
쓴다.

## 2. 글자 — 뒤에서 읽혀야 한다

- 한 장에 글은 **최대 5줄**
- 제목은 `<h2>`, 본문은 `<p>` 또는 `<ul><li>`. 크기를 직접 지정하지 않는다
  (템플릿이 화면 크기에 맞춰 이미 잡아 놓았다)
- **한 장에 메시지 하나.** 두 가지를 말하고 싶으면 장을 나눈다
- 문장은 짧게. 발표할 때 소리 내어 읽을 문장이다

흔한 실수: 글을 많이 넣으면 열심히 한 것처럼 보인다고 생각하는 것.
반대다. 뒤에 앉은 사람이 못 읽으면 없는 것과 같다.

## 3. 여백 — 채우지 않는다

한 장에 그림 하나 + 짧은 글이면 충분하다. 빈 곳을 남겨 두면
보는 사람 눈이 쉬고 중요한 것이 눈에 들어온다.

그림은 `class="media"` 를 붙인다. 크기가 화면에 맞게 조절된다.

## 4. 움직임 — GSAP 과 anime.js

템플릿에 이미 불러와 있다. 학생이 설치할 것은 없다.

| 라이브러리 | 언제 |
|---|---|
| **GSAP** | 장이 나타날 때 글·그림이 스르륵 등장 (템플릿에 기본 동작이 이미 들어 있다) |
| **anime.js** | 숫자가 올라가는 효과, 글자 하나씩 나타나기 같은 낱개 연출 |

### 기본 등장 애니메이션은 이미 동작한다

장을 넘길 때마다 그 장의 요소가 아래에서 위로 살짝 올라오며 나타난다.
**아무것도 안 해도 된다.** 학생이 "움직이게 해줘" 라고 하면 이미 되고 있다고
알려주고, 특별한 효과를 원하는지 물어본다.

### 특별한 효과를 넣을 때

`index.html` 맨 아래 `<script>` 안에 넣는다. 예를 들어 숫자가 올라가는 효과:

```html
<section class="slide">
  <h2>바다에 버려지는 플라스틱</h2>
  <p><span class="count" data-to="800">0</span>만 톤</p>
</section>
```

```javascript
// 장이 보일 때 숫자를 0에서 목표까지 올린다
function 숫자올리기(slide) {
  slide.querySelectorAll('.count').forEach(function (el) {
    anime({
      targets: el,
      innerHTML: [0, Number(el.dataset.to)],
      round: 1,
      duration: 1200,
      easing: 'easeOutQuad'
    });
  });
}
```

### 움직임 규칙 (지키지 않으면 오히려 싸 보인다)

- **한 장에 특별한 효과는 1개까지.** 다 움직이면 아무것도 눈에 안 들어온다
- **0.6초 안에 끝낸다.** 발표 중에 기다리게 하면 안 된다
- 글자가 **읽히기 전에 사라지는 움직임**은 넣지 않는다
- 빙글빙글 돌기·튕기기는 쓰지 않는다. 한 번은 웃기지만 발표 내내 유치해 보인다
- 움직임은 **내용을 돕는 것**이어야 한다. 쓰레기가 쌓이는 주제면 위에서 떨어지는
  움직임처럼, 메시지와 방향이 맞아야 한다

### 반드시 지킬 것

```javascript
// 움직임을 불편해하는 사람을 위한 설정을 존중한다
var 움직임싫어함 = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
if (움직임싫어함) { /* 애니메이션을 건너뛰고 바로 보여준다 */ }
```

템플릿의 기본 동작에는 이미 들어 있다. 새로 만드는 효과에도 넣는다.

그리고 **글을 숨기고 시작하는 효과**(투명도 0 에서 시작, 아래에서 올라오기 등)를
만들 때는 반드시 안전망을 같이 넣는다. 움직임이 어떤 이유로든 안 돌면 글이
영원히 안 보이고, 그게 발표 중에 일어나면 되돌릴 수 없다.

```javascript
// 1.2초 뒤에도 아직 안 보이면 움직임을 포기하고 글을 보여준다
setTimeout(function () {
  if (getComputedStyle(el).opacity !== '1') {
    el.style.opacity = '';
    el.style.transform = '';
  }
}, 1200);
```

실제로 겪은 일이다: 화면에 안 보이는 탭에서는 브라우저가 움직임을 멈춰서
글이 투명한 상태로 굳었다. 템플릿은 이제 안 보이는 탭이면 움직임을 건너뛴다.

## 5. 라이브러리를 더 쓰고 싶을 때

CDN 으로 불러와도 된다. 캠프장 인터넷은 잘 된다.

단 **패키지 설치·번들러·프레임워크는 쓰지 않는다.** `npm install` 이 한 번
터지면 그 팀은 5시간 안에 발표자료를 못 만든다. `<script src="...">` 한 줄로
끝나는 것만 쓴다.

그리고 CDN 이 늦게 오거나 실패해도 **글은 보여야 한다.** 라이브러리가 없으면
애니메이션만 건너뛰고 내용은 그대로 나오게 만든다.

```javascript
if (window.gsap) { /* 애니메이션 */ } else { /* 그냥 보여주기 */ }
```

## 6. 학생에게 말할 때

기술 이야기를 하지 않는다.

- "GSAP 으로 stagger 애니메이션을 넣었어요" ✕
- "장을 넘길 때 글자가 스르륵 올라오게 했어요" ○

효과를 넣은 뒤에는 `/보여줘` 로 직접 보게 한다. 눈으로 보고 마음에
드는지 물어본다.
