# 미디어 만들기

## 반드시 `$LOCALAPPDATA/Programs/camp-tools/camp-media.sh` 로만 만든다

`higgsfield` 명령을 직접 실행하지 않는다. 그러면 비용 제한이 걸리지 않는다.

**경로를 그대로 쓴다. .**

```bash
"$LOCALAPPDATA/Programs/camp-tools/camp-media.sh" --kind <그림|대표|영상> --prompt <영어 설명> --team-dir <팀폴더>
```

명령을 찾지 못하면 `find` 로 디스크를 뒤지지 마라. 학생에게
"그림 만들기 도구가 없어요. 선생님을 불러 주세요." 라고 말하고 끝낸다.

성공하면 저장된 파일의 상대경로가 한 줄 출력된다. 예: `assets/그림-1.jpg` (종류에 따라 이름이 다르다 — 출력된 경로를 그대로 쓴다)

## 네 가지 종류

| kind | 언제 쓰나 | 만드는 데 걸리는 시간 |
|---|---|---|
| `그림` | 보통의 그림. **기본으로 이걸 쓴다** | 몇 초 |
| `대표` | 발표 표지처럼 딱 한 장 중요한 것 (더 크고 선명하게 나온다) | 몇 초 |
| `영상` | 짧은 캠페인 영상 | 1~2분 |

**횟수 제한은 없다.** 마음에 들 때까지 다시 만들어도 된다.
학생에게 "몇 번밖에 못 만들어요" 라고 말하지 마라. 사실이 아니다.

모델과 영상 길이는 도구가 정해 놓았고 바꿀 수 없다. 바꾸려고 시도하지 마라.

**중요:** 학생이 "포스터 만들어 줘" 라고 해도 처음에는 `그림` 을 쓴다.
학생이 마음에 들어하는 그림이 나온 다음, 그것을 발표 표지로 쓸 때만
`대표` 로 한 번 다시 만든다.

## 프롬프트는 영어로 쓴다

학생은 한국어로 말한다. 영어로 바꿔서 넘긴다.

- 학생: "바다에 쓰레기 떠 있는 슬픈 그림"
- `--prompt "sad ocean scene with floating plastic trash, children's illustration style, soft colors, no text"`

프롬프트에 넣을 것:
- 무엇이 보이는지
- `children's illustration style` 또는 `flat vector illustration` 같은 그림 스타일
- `no text` — **보통 그림(`그림`)에는 항상 넣는다**

## 글자를 넣을 수 있는 것은 `대표` 뿐이다

`대표` 는 한국어 글자를 정확히 써 주는 모델을 쓴다. 실제로 확인했다 —
"바다를 지켜요" 가 또렷하게 나온다. 그러니 **캠페인 포스터에 표어를
넣어 달라고 하면 `대표` 로 만들어 준다.**

```
--kind 대표 --prompt 'campaign poster, blue ocean with a sea turtle,
  large clear Korean text at the top that reads "바다를 지켜요",
  children poster style, bold letters'
```

넣을 한국어는 **따옴표 안에 정확히** 적는다. 길면 틀릴 수 있으니
**한 줄, 열 글자 안쪽**으로 짧게 한다.

보통 그림(`그림`)은 글자가 깨진다. 그래서 `no text` 를 넣는다.

## 슬라이드의 제목과 본문은 그림에 넣지 않는다

포스터 안의 표어는 그림에 넣어도 되지만, **발표자료의 제목과 설명은
`index.html` 에 진짜 글자로 넣는다.** 이유가 있다.

- 프로젝터에서 더 또렷하다 (그림 속 글자는 뿌옇다)
- 오타를 바로 고칠 수 있다
- 뒤에 앉은 사람도 읽힌다

그림은 배경·삽화를 맡고, 발표 문구는 그 위에 얹는다
(`slide-design` 스킬 참고).

프롬프트에 넣지 말 것:
- 사람 얼굴, 실제 인물 이름, 실제 상표
- 학생 이름·학교 이름
- 무섭거나 폭력적인 묘사

## 실패했을 때

exit 코드로 무슨 일인지 알 수 있다.

| 코드 | 뜻 | 학생에게 할 말 |
|---|---|---|
| 4 | 시킨 내용이 잘못됨 | 학생 탓이 아니다. 프롬프트를 고쳐서 다시 시도한다 |
| 5 | 만들기 실패 | 도구가 준 말을 그대로 전한다. 한 번만 다시 시도한다 |
| 6 | 열쇠가 없음 | "그림 만들기 도구에 문제가 생겼어요. 선생님을 불러 주세요." 다시 시도하지 않는다 |
| 7 | 재료가 다 떨어짐 | "오늘 그림 만들기 재료가 다 떨어졌어요. 선생님을 불러 주세요." 다시 시도하지 않는다 |

5번은 한 번만 다시 시도한다. 두 번 연속 실패하면 학생에게 다른 것을
먼저 하자고 제안한다.

## 만든 뒤에 — 반드시 그림을 띄워 준다

1. 출력된 상대경로를 기억한다. `디자이너` 가 발표자료에 넣을 때 쓴다.
2. `우리팀.md` 의 "만든 것" 목록에 한 줄 추가한다.
3. **그림은 저절로 보인다.**

   **도구가 알아서 띄워 준다.** 만들기가 끝나면 그림이 브라우저 창에
   저절로 열린다. 학생은 바로 눈으로 본다.

   그러니 따로 여는 명령을 실행하지 마라. 두 번 열리기만 한다.
   (사진 앱으로 열면 처음 실행 때 동의 창이 떠서 학생이 막힌다 — 실측.
    그래서 도구가 브라우저로 띄운다.)

4. 그러고 나서 짧게 한마디 한다. 명령어나 프롬프트 원문은 보여주지 않는다.

   좋음: "다 만들었어요! 그림이 열렸어요, 어때요?"
   나쁨: "assets/그림-1.jpg 에 저장했습니다"
   나쁨: "camp-media.sh --kind 그림 --prompt ... 를 실행했습니다"
