캠프 프로그램 받기

캠프에서 쓸 프로그램입니다. 캠프 시작 전에 미리 받아 두면 당일에 바로 시작할 수 있어요.

프로그램 받기

Windows 10 이상 · 약 350MB · 받는 데 몇 분 걸려요

받은 다음에 할 일 — 3단계

  1. 받은 파일을 두 번 누르세요. 창이 하나 열립니다.
  2. 열린 창 위쪽에 모두 압축 풀기 라고 써 있는 단추가 있어요. 한 번 누르세요.
    그다음 나오는 창에서 압축 풀기 를 한 번 더 누르면 됩니다.
  3. 새로 만들어진 폴더 안에서 창의디자인캠프 설치 를 두 번 누르세요.
    나머지는 저절로 됩니다. 5~10분쯤 걸려요.

"Windows가 PC를 보호했습니다" 창이 나오면

처음 실행할 때 파란 창이 뜰 수 있어요. 고장이 아닙니다.

  1. 추가 정보 를 한 번 누르세요.
  2. 아래에 나타나는 실행 을 한 번 누르세요.

설치가 끝나면

바탕화면에 그림 다섯 개가 생깁니다. 점검 을 두 번 눌러서 초록 표시가 다 켜지는지 한 번만 확인해 주세요. 1분쯤 걸립니다.

캠프 당일에는 캠프 시작 만 두 번 누르면 됩니다.

잘 안 될 때

받다가 멈추면 다시 받아 주세요. 설치가 안 되면 캠프 당일에 도와드리니 그냥 오시면 됩니다. 미리 설치하지 못해도 괜찮습니다.
