사양의 학생 UX 요구가 설치된 환경에서 그대로 재현됐다.

## 확인하지 못한 것 (정직하게)

1. **`Read-Host` 프롬프트 상호작용** — 리다이렉트된 stdin 을 `Read-Host` 가
   읽지 않아 자동 검증이 불가능했다. `Start-CampLauncher -Number -Name` 인자
   경로로 우회 검증했다. **사람이 직접 타이핑해 한 번 확인해야 한다**
2. **아무 것도 설치되지 않은 깨끗한 노트북** — 이 PC 에는 Node·Python·Git 이
   이미 있었다. 전체 설치 경로와 실제 소요 시간은 미검증
3. **데스크탑 앱 GUI 안에서의 조작** — 앱이 열리고 프로젝트가 등록된 것까지
   확인했으나, 앱 화면에서 세션을 만들어 `/포스터` 를 눌러보는 것은
   GUI 자동화가 필요해 하지 않았다. 서버 API 로 동일 경로를 검증했다
4. **백신 차단** — 이 PC 의 백신 설정에서는 발생하지 않았다. 다른 노트북에서는
   발생할 수 있다

## 정리

개발 환경은 E2E 후 복원했다:
- `~/.config/opencode` → 원래 설정 복원
- 데스크탑 앱 상태(`opencode.global.dat`, `opencode.settings`) → 백업에서 복원
- 남긴 것: `%LOCALAPPDATA%\Programs\opencode-cli` (점검용 CLI), Cascadia 글꼴,
  `~/창의디자인캠프/` (연습·팀 폴더). 모두 무해하며 필요하면 지워도 된다
